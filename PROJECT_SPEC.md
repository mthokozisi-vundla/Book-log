BOOK LOG — VERSION 1

Project Purpose
---------------
Book Log is a personal reading journal and knowledge tracker.

The purpose of the application is to help me remember what I read,
what I understood, what I learned, and how the information applies
to my life.

Core Problem
------------
I read books, but I can forget what I learned from them.

Book Log solves this by allowing me to record my reading progress
and document my thoughts and knowledge chapter by chapter.


V1 FEATURES
-----------

1. Book Library
- Add a book
- Edit a book
- Delete a book
- Store a book cover image
- Store title
- Store author
- Store total pages
- Store reading status
- Store start date
- Store finish date

2. Chapter Journal
- Add chapters to books
- Edit chapters
- Delete chapters
- Store chapter number
- Store chapter title
- Store page range
- Record what I understood
- Record what I learned
- Record how the chapter applies to my life
- Record my thoughts
- Record a key takeaway

3. Reading Tracker
- Log daily reading
- Record pages read
- Record start and end pages
- Add optional reading notes
- Track current page
- Calculate reading progress
- Track reading streak

4. Dashboard
- Books read
- Pages read
- Reading days
- Current reading streak
- Currently reading book
- Current book progress

5. Statistics
- Books read in a year
- Pages read in a year
- Reading days
- Average pages per reading day

---------------

V1 is complete when I can:

1. Add a book.
2. See the book in my library.
3. Open the book.
4. Add chapters.
5. Open a chapter.
6. Write my personal notes.
7. Save the notes.
8. Log pages that I read.
9. See my reading progress update.
10. Track my reading streak.
11. Complete a book.
12. See my yearly reading statistics.
13. Use the application successfully with a real book.
